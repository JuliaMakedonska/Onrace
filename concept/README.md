# Concept

Onrace's visual concept: Direction A, **Podium** (chosen 2026-10-13). Rules and decisions are in `concept.md`; the live stand is `concept.html` ([live](https://juliamakedonska.github.io/Onrace/concept/concept.html)).

| File | What it is |
|---|---|
| `concept.md` | The rules: designer's taste, Hierarchy rules 1–6, Color rules 1–3 (3b overridden by the designer), race card anatomy, map, Deferred to Lesson 7, the step 7 check |
| `references.md` | References and the photo log (source, license, crop) |
| `tokens.css` | Every value (color, type, shape, spacing, icons, motion) |
| `map.css` | Map tokens and the Natural Earth masks; linked only by the Race browse pages |
| `components.css` | Components, from tokens only |
| `concept.html` | The stand, generated by `../scripts/concept/build_stand.py` |
| `first-screen.html` | Harness that measures how many race cards fit on a 390×844 first screen |
| `directions.html`, `directions-round-1.html` | The three directions compared, and the rejected round 1 |

Build scripts (from the repo root): `python3 scripts/concept/build_stand.py` checks the color rules, every contrast pair and that every token is signed, then writes the stand; `python3 scripts/concept/build_map.py` regenerates the map block in `map.css`. Copy changed files to `../public/concept/`.
