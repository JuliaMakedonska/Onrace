# Concept

Onrace's visual concept: Direction A, **Podium** (chosen 2026-10-13). Rules and decisions are in `concept.md`; the live stand is `concept.html` ([live](https://juliamakedonska.github.io/Onrace/concept/concept.html)).

| File | What it is |
|---|---|
| `concept.md` | The rules: designer's taste, Hierarchy rules 1–6, Color rules 1–3 (3b overridden by the designer), race card anatomy, map, Deferred to Lesson 7, the step 7 check |
| `references.md` | References and the photo log (source, license, crop) |
| `concept.html` | The stand, generated by `../scripts/concept/build_stand.py` |
| `stand.css` | The stand's own layout and the docs layer's tokens (values from `../tokens/tokens.css`) |
| `first-screen.html` | Harness that measures how many race cards fit on a 390×844 first screen |
| `directions.html`, `directions-round-1.html` | The three directions compared, and the rejected round 1 |

Every value and component now lives in the kit: `../tokens/tokens.css` (values), `../components/` (components, bundled into `index.css`) and `../ui/map-data.css` (the map's data), since Lesson 8 step 4 (2026-10-28). Before that, `../ui/kit.css` and `../ui/map.css` (Lesson 7 step 3a, 2026-10-18, when `tokens.css`, `components.css` and `map.css` were merged into them and removed).

Build scripts (from the repo root): `python3 scripts/concept/build_stand.py` checks the color rules, every contrast pair and that every token is signed, then writes the stand; `python3 scripts/concept/build_map.py` regenerates the map block in `../ui/map-data.css`. `build_stand.py` mirrors the stand, the kit and the map to `../public/`.
