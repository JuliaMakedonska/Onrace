Form rows: text fields, hints, errors, with every state beside it

From DESIGN.md

Form rows: Log result and the sign-in screens are grouped forms, as iOS: a label (15px Text 1) and its field in a row on the rows' level (--surface on the page, --group on a sheet), the value in Text 1, left-aligned; a long value (the official result link) stacks under its label. One row height everywhere: every grouped row is 52px (--grouped-row-min, the 44pt target plus 8), in a sheet (Filters, Log result, Add official result link) and outside one (Sign in / Sign up, Reset password, New password, Profile): text, a menu, a date pill, a read-only value, a checkmark row and a navigation row all one height; a field or menu fills its row, so a tap anywhere on it reaches the field; a stacked field keeps 8px above and below (--grouped-row-pad). The same field anatomy everywhere: one line, the label and its field, or, where the title names the field, the field alone with its label as its accessible name. Pickers sit at the row's trailing edge: a menu value with its chevron, a date on a --raised pill. Editable text values are Text 1; read-only values (Profile's Email) and menu values are Text 2, as iOS Settings. Hints are the group's footer (13px Text 2). The field error (designer, 2026-10-30, iOS style): no ring and no line on the field; a coral footnote line (13px / 400 --error) after the 15px error icon, under its group, outside the group's surface, never inside a row: 8px below the group, at the body's line height (1.45), in the hint's place, which it replaces while it shows; in a group of several fields each field's error is its own footnote, in the fields' order. Profile's save error is the same footnote, with its Try again link. The field carries aria-invalid and aria-describedby (the error, not the hidden hint). Log result, New password and Profile's row error are the same. Focus is the 2px ring outside the field, so an error and a focus never look alike. A navigation row (Find in race catalog) ends in a Text 2 disclosure chevron; it goes while a race is linked (the card's Unlink changes it). The finish time takes the numeric keypad. Empty required fields hold the bar's confirm disabled until they're filled (Sign in, Create, Send), so an empty submit never reaches the browser's bubble; password rows say "Required". While saving, the whole form is locked in one treatment, the disabled one: every control and its label at --opacity-disabled, the bar's Cancel with it; the help text stays Text 2.
