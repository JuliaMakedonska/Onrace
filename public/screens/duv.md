# DUV Ultra Marathon Statistics — screenshot captured

Captured via Playwright MCP, 2026-09-02: `duv-home.png` (full-page start page, public, no login wall).

**Confirmed via page text:** run by "Deutsche Ultramarathon-Vereinigung e.V." (a German nonprofit association, not a company). The database contains, at time of capture, **10,634,092 performances of 2,546,493 runners across 120,145 ultramarathon events**. Rankings are auto-generated from the database for "ranking eligible" events. Everything is hyperlinked (athlete → full result history; event → complete results list).

**Submission mechanism, quoted:** "If you are a race director we are happy to include the results of your race in our database. The easiest way is by sending the results as Excel or text file (no PDF!) to results@statistik.d-u-v.org." Corrections/amendments are invited via a contact form — race directors push results, athletes don't self-report, and errors are acknowledged as "inevitable... often already contained in the original result lists."

**Team:** a named, credited group of volunteer statisticians per region (Asia, ITA, GBR/IRL/FIN/ISL, AUS/NZL, USA/CAN, BEL, SWE, etc.) plus regular helpers — an all-volunteer operation.

**Monetization:** none observed beyond an unsold "Advertise here! 300 x 60 pixel" banner placeholder — no subscription, no paid tier, consistent with its nonprofit-association structure.

**Visual note:** the site's design is unmistakably dated (table-based 1990s-style layout, default link-blue), still functioning and actively maintained content-wise (rankings/records current) — a useful reference for "content can stay authoritative and actively used even when the UI investment is near zero," a different lesson than Athlinks' stale-content problem.

**Relevance to Onrace:** confirms the original audit's claim that DUV is director-submitted, not self-reported by athletes — the opposite trust model from Onrace's plan. Its single-sport depth (ultras only) and volunteer/nonprofit structure make it a reference for domain depth, not a product-shape competitor.
