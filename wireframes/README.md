# Wireframes

Browse them in [`index.html`](./index.html) (live: https://juliamakedonska.github.io/Onrace/wireframes/). Comes after `../research/` and the IA, and before `../concept/`.

- [`_conventions.md`](./_conventions.md): the rules every page follows.
- [`_screens.md`](./_screens.md): which states each screen has, and why.
- [`_critique.md`](./_critique.md): the latest review, with fixes.

`../public/wireframes/` is a mirror for GitHub Pages; keep it in sync.
