# Wireframes

Low-fidelity, grayscale, iOS-structured HTML wireframes for every screen in [`../sitemap.md`](../sitemap.md): 10 screens and 35 pages, one per real state. Browse them in [`index.html`](./index.html) (live: https://juliamakedonska.github.io/Onrace/wireframes/). Comes after `../research/` and the IA, and before `../concept/`.

- [`_conventions.md`](./_conventions.md): the rules every page follows.
- [`_screens.md`](./_screens.md): which states each screen has, and why.
- [`_critique.md`](./_critique.md): the latest review, with fixes.

- [`_wireframe/`](./_wireframe/README.md): the **frozen snapshot**. These are the 35 pages as they were at the end of Lesson 5, commit `7347c27` (the last commit before `ae28e5b` first painted `race-browse.html`; its `wireframes/` tree is identical to Lesson 5's final commit, `a0836c9`, 2026-09-30). The viewer's **Wireframe** mode shows it; **Design** mode (the default) shows the working pages in this folder. It's read-only history, not a copy to maintain: never edit it.

`../public/wireframes/` is a mirror for GitHub Pages; keep it in sync (the snapshot's mirror, `_wireframe/`, is written once and never changes).
