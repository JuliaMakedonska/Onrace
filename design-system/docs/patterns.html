Patterns

Patterns

A pattern is a composition of existing components that already stands on three or more screens. Each is one file in design-system/patterns/, with no style of its own.

Tab screen

A top-level screen: its large title over its own content, the tab bar floating at the bottom.

Use the pattern

For a destination you reach from the tab bar: Discover, Results, Profile. The title names the tab, and the bar action, if there is one, is the screen's one primary action.

Use the components

A screen below the top level has no large title and no tab bar: it takes the Top bar on its own, as a pushed screen.

Composed of Large title header, Tab bar, Results row

Stands on 3 screens

Empty or error state

What a list or a screen shows when it has nothing to show or couldn't load: a heading, one line, one action.

Use the pattern

When the whole content area is empty or failed to load: no results, no match, the connection dropped. The action is the one way on: Try again, or the task that fills it.

Use the components

An error about one field or one save stays where it happened: a Field error under the field, a Form alert at the top of the form, a Status line on the row.

Composed of State message, Primary button

Grouped form

Fields a person fills in, grouped as iOS: labelled rows of one height, the hint under the group, an error under the group, one per field.

Use the pattern

For a form of more than one field, and for settings that save as you make them. An error replaces only its own field's helper; a group note stays.

Use the components

One field on its own, such as the search, is a Search field, not a group.

Composed of Text field, Field hint, Field error, Grouped settings rows, Gate layout

Pushed screen

A screen one level down: the top bar with back, named for the screen it returns to, over the screen's content, with no tab bar.

Use the pattern

For a detail, or a step inside a task: Race detail, Result detail, Race picker, Reset password, New password. Back always names the parent.

Use the components

A task you leave with Cancel, such as Log result or Sign in, is a sheet or a gate: its Top bar takes Cancel, not back.

Composed of Top bar, List intro, Race card
