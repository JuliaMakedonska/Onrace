From DESIGN.md

Checkmark row: a sport type is a row; checked, a 26px Solar check in --text-primary (the control tint, C4) at its trailing edge (the glyph about 17px wide, as HIG's list checkmark), nothing when off. Race picker's linked race carries the same checkmark. Never the accent. Every system-drawn control takes the same tint (accent-color, C4).
