Proof URL and note

The official result link in full, with the note that Onrace doesn't verify results.

Example

Berlin Marathon

Finish time
3:12:48
Race date
21 September 2025
Sport type
Marathon

Official result link

https://berlin.r.mikatiming.com/2025/

Self-reported · via berlin.r.mikatiming.com

Onrace doesn’t verify results. The official result is the evidence.

Usage

When to use

The full official result link, so a person can copy it for an application.

See it: Result detail ↗

When not to

Opening the official result is the action bar's button. Use Sticky action bar.

See it: Result detail ↗

From DESIGN.md

Result detail: as Race detail, without a photo: the race name (Item, 17px / 600), then the finish time leading the screen (Schibsted 56px, --size-time-hero, the largest element) 4px under its label, the facts, the proof section (the full link, breaking only after /. -, then Copy link, the proof line, the note "Onrace doesn't verify results."), and the action bar's capsule "Open official result on <domain>". The Open button reads "Open official result" (its name carries the domain), the caption "Opens the official timing site.", and a link that won't open is the confirm alert, so the action bar keeps one height. With no official result link yet: no link and no Copy link; the proof line says so and the note is "Without the official result link, this result has no evidence."; the action bar's primary is "Add official result link", in Open official result's place.
