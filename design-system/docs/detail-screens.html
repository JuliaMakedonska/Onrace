From DESIGN.md

Result detail: as Race detail, without a photo: the race name (Item, 17px / 600), then the finish time leading the screen (Schibsted 56px, --size-time-hero, the largest element) 4px under its label, the facts, the proof section (the full link, breaking only after /. -, then Copy link, the proof line, the note "Onrace doesn't verify results."), and the action bar's capsule "Open official result on <domain>". The Open button reads "Open official result" (its name carries the domain), the caption "Opens the official timing site.", and a link that won't open is the confirm alert, so the action bar keeps one height. With no official result link yet (2026-11-06): no link and no Copy link; the proof line says so and the note is "Without the official result link, this result has no evidence."; the action bar's primary is "Add official result link", in Open official result's place.
