Step 5 · the theme stress test

Lesson 8, 2026-10-30. Onrace is dark-only (C5), so the test is a light theme: tokens/tokens.css gained a [data-theme="light"] block that overrides semantic roles only, on iOS light (grouped backgrounds, label colors) with Podium kept: the amber fill, black-and-white photos, neutral chips. Every state below in both themes at 390×844, 105 states, dark on the left. Open any state with ?theme=light, or in the wireframes viewer with its Light / Dark switch.

Holes found in components/ (each fixed in the component): (1) top-bar.css: the bar action's hover read --accent-hover, the role the primary fill's hover also reads. In light one value can't be both a fill under dark text and text on a light bar, so the bar action now reads a new role, --accent-ink-hover (same value as before in dark). (2) date-field.css: the native date input had color-scheme: dark written into it, so its picker would stay dark in light; it now inherits the theme's. No component read a color primitive.

Not decided here: whether the light theme stays in the product. Dark is unchanged to the pixel (checked against the commit before this step).
